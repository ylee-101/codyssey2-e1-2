# 나만의 Python 콘솔 퀴즈 게임

## 가장 먼저 할 일

한 번에 이 README 전체를 처리하지 않는다. `todo/` 폴더의 파일을 **번호 순서대로 딱 하나만** 열어 수행한다. 현재 파일의 완료 조건을 만족하면 다음 번호 파일로 넘어간다.

시작 파일: [`todo/00_시작하기.md`](todo/00_시작하기.md)

## 프로젝트 개요

Python 기초 문법, 객체 지향 프로그래밍, JSON 파일 입출력, Git/GitHub 사용법을 익히기 위한 콘솔 기반 퀴즈 게임을 만든다. 사용자는 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 조회, 최고 점수 확인, 종료 기능을 선택할 수 있어야 한다.

프로그램을 다시 실행해도 직접 추가한 퀴즈와 최고 점수가 유지되도록 프로젝트 루트의 `state.json`에 데이터를 저장한다.

## 퀴즈 주제와 선정 이유

- 주제: **퀴즈 게임을 만들며 배우는 Python 기초**
- 선정 이유: 이 과제를 완성하는 데 필요한 Python 개념을 퀴즈 주제로 삼는다. 코드를 작성하기 전에 개념을 짧게 학습하고, 직접 만든 퀴즈로 다시 확인할 수 있어 초보자에게 적합하다.

기본 퀴즈는 아래 학습 목록의 변수, 자료형, 조건문, 반복문, 함수, 클래스, 파일과 JSON, 예외 처리 내용을 바탕으로 12개 작성한다.

## 과제 전 Python 학습 체크리스트

아래 순서대로 한 항목씩 학습하고, 예제 코드를 직접 실행한다. 모든 내용을 완벽히 외우기보다 **무엇을 할 때 사용하는지** 이해하는 것을 목표로 한다.

### 1. 실행과 출력

- [ ] Python 파일을 만들고 `python main.py`로 실행한다.
- [ ] `print()`로 메뉴와 안내 문구를 출력한다.
- [ ] `input()`으로 사용자의 메뉴 번호와 퀴즈 답을 입력받는다.

### 2. 변수와 자료형

- [ ] 변수: 값을 이름으로 저장하는 방법을 이해한다. 예: `score = 0`
- [ ] `int`: 정수(점수, 메뉴 번호, 정답 번호)에 사용한다.
- [ ] `str`: 문자열(문제, 선택지, 입력값)에 사용한다.
- [ ] `bool`: 참/거짓(정답 여부)에 사용한다.
- [ ] `list`: 여러 퀴즈 또는 4개 선택지를 순서대로 저장한다.
- [ ] `dict`: JSON으로 저장할 퀴즈 한 개의 필드와 값을 표현한다.

### 3. 조건문과 반복문

- [ ] `if` / `elif` / `else`로 메뉴 번호와 정답 여부에 따라 다른 동작을 만든다.
- [ ] `while`로 종료할 때까지 메뉴를 반복해서 표시한다.
- [ ] `for`로 퀴즈 목록을 하나씩 출제하거나 출력한다.

### 4. 함수와 입력 검증

- [ ] 함수를 정의하고 매개변수와 반환값을 사용한다.
- [ ] `strip()`으로 입력 앞뒤 공백을 제거한다.
- [ ] `int()`로 숫자 문자열을 숫자로 바꾼다.
- [ ] 빈 입력, 숫자가 아닌 입력, 허용 범위 밖의 입력을 다시 받는다.

### 5. 클래스와 객체

- [ ] 클래스는 같은 종류의 데이터와 동작을 묶는 설계도임을 이해한다.
- [ ] `Quiz` 클래스로 문제·선택지·정답을 하나의 퀴즈 객체로 만든다.
- [ ] `QuizGame` 클래스로 메뉴, 점수, 퀴즈 목록 등 게임 전체를 관리한다.
- [ ] `__init__`과 `self`의 역할을 이해한다.

### 6. 파일, JSON, 예외 처리

- [ ] `open()`으로 파일을 열고 읽고 쓴다.
- [ ] `json.load()`와 `json.dump()`로 데이터를 불러오고 저장한다.
- [ ] `try` / `except`로 잘못된 숫자 입력과 파일 오류를 처리한다.
- [ ] `KeyboardInterrupt`, `EOFError`, 손상된 `state.json`에도 안전하게 종료하거나 기본 데이터로 복구한다.

### 7. Git과 GitHub

- [ ] `git init`, `add`, `commit`, `push`로 작업을 저장소에 기록하고 올린다.
- [ ] `checkout`으로 브랜치를 만들고, 기능 구현 후 `merge`로 `main`에 합친다.
- [ ] `clone`으로 저장소를 복제하고, `pull`로 변경 사항을 받아온다.

## 개발 환경 및 제약 사항

- Python 3.10 이상
- 외부 라이브러리 없이 Python 표준 라이브러리만 사용
- 데이터 파일은 프로젝트 루트의 `state.json`에 UTF-8 인코딩으로 저장
- 최소 2개 이상의 클래스로 책임을 분리
- 모든 로직을 하나의 함수에 작성하지 않고 기능별 메서드/함수로 분리

python3 src/main.py

## 기능 목록

### 1. 메뉴

- 프로그램 실행 시 아래 기능을 선택할 수 있는 메뉴를 출력한다.
  - 퀴즈 풀기
  - 퀴즈 추가
  - 퀴즈 목록
  - 점수 확인
  - 종료
- 메뉴 범위를 벗어난 숫자, 숫자가 아닌 값, 빈 입력을 안내하고 다시 입력받는다.

### 2. 퀴즈 풀기

- 저장된 퀴즈를 순서대로 출제한다.
- 각 문제에 대해 1~4번 중 정답을 입력받고 정답/오답을 표시한다.
- 모든 문제를 푼 뒤 정답 수와 점수를 표시한다.
- 퀴즈가 없는 경우를 안내한다.
- 매 게임 후 최고 점수와 비교하여 갱신하고 저장한다.

### 3. 퀴즈 추가

- 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 새 퀴즈를 등록한다.
- 입력 검증 후 등록한 퀴즈를 즉시 `state.json`에 저장한다.

### 4. 퀴즈 목록

- 저장된 모든 퀴즈의 번호와 문제를 표시한다.
- 퀴즈가 없는 경우를 안내한다.

### 5. 점수 확인

- 현재 최고 점수(또는 최고 정답 수)를 표시한다.
- 아직 게임 기록이 없을 때의 안내를 제공한다.

### 6. 예외 및 데이터 복구 처리

- 숫자 입력 전후의 공백을 제거한다.
- 숫자 변환 실패, 범위 밖 숫자, 빈 입력은 안내 후 입력 흐름으로 복귀한다.
- `KeyboardInterrupt`(Ctrl+C)와 `EOFError` 발생 시 가능한 범위에서 저장하고 안전하게 종료한다.
- `state.json`이 없으면 기본 퀴즈 데이터를 사용한다.
- `state.json`이 손상되었거나 파일 읽기/쓰기 오류가 발생하면 안내하고 기본 데이터로 복구 또는 초기화한다.

## 코드 구조

### `Quiz` 클래스

개별 퀴즈를 표현한다.

- 속성: `question`, `choices`, `answer`
- 선택지: 기본 4개
- 정답: 1~4번 번호로 관리
- 메서드 예시: 퀴즈 출력, 정답 확인, 딕셔너리 변환

### `QuizGame` 클래스

게임 전체를 관리한다.

- 속성: 퀴즈 목록, 최고 점수
- 메서드: 메뉴 표시, 퀴즈 풀기, 퀴즈 추가, 목록 보기, 점수 확인, 파일 저장/불러오기

## 데이터 파일 설명

경로: 프로젝트 루트의 `state.json`

역할: 사용자가 추가한 퀴즈와 최고 점수를 프로그램 종료 후에도 유지한다.

최소 스키마 예시:

```json
{
  "quizzes": [
    {
      "question": "Python에서 값을 이름에 저장할 때 사용하는 것은 무엇인가?",
      "choices": ["변수", "반복문", "주석", "파일"],
      "answer": 1
    }
  ],
  "best_score": 3
}
```
