# 11. 브랜치에서 퀴즈 풀기 구현

## 이번 파일에서 할 일

- [ ] `git checkout -b feature/play-quiz`로 작업 브랜치를 만든다.
- [ ] 메뉴 1번에서 모든 퀴즈를 하나씩 보여 주고 정답 번호를 입력받게 한다.
- [ ] 맞으면 정답, 틀리면 오답을 알리고 정답 수를 센다.
- [ ] 마지막에 `12문제 중 N문제 정답`을 출력한다.
- [ ] 커밋·푸시 후 `main`으로 돌아와 `git merge feature/play-quiz`와 `git push`를 실행한다.

## 완료 기준

메뉴 1번을 선택하면 12문제를 풀고 결과를 보며, Git 브랜치 병합 기록이 있다.
