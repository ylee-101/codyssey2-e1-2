# 16. state.json 저장과 불러오기

## 이번 파일에서 할 일

- [ ] `json` 모듈을 가져온다.
- [ ] `Quiz`를 딕셔너리로 바꾸는 방법과 딕셔너리에서 다시 만드는 방법을 만든다.
- [ ] 퀴즈 목록과 `best_score`를 프로젝트 루트의 `state.json`에 UTF-8로 저장한다.
- [ ] 프로그램 시작 때 파일이 있으면 데이터를 불러오고, 없으면 기본 12개 퀴즈로 시작한다.
- [ ] 퀴즈 추가와 게임 종료 후 저장하고, 재실행해 유지되는지 확인한다.
- [ ] 완료 후 커밋한다.

## 완료 기준

새 퀴즈와 최고 점수가 프로그램을 껐다 켜도 유지된다.
