# 04. 변수와 자료형 맛보기

## 이번 파일에서 할 일

- [ ] `main.py` 맨 아래에 아래 코드를 임시로 추가하고 실행한다.

```python
score = 0
game_title = "나만의 퀴즈 게임"
is_running = True

print(game_title)
print(score)
print(is_running)
```

- [ ] `score`, `game_title`, `is_running`의 값을 각각 바꿔 보고 다시 실행한다.
- [ ] 실험한 코드는 이해했다면 지워도 된다.

## 배운 것

변수는 값을 담아 두는 이름표다. `int`는 정수, `str`은 글자, `bool`은 참/거짓을 뜻한다.

## 완료 기준

변수 이름을 바꾸면 출력 결과도 바뀐다는 것을 확인했다.
