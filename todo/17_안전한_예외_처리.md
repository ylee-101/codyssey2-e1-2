# 17. 안전한 예외 처리

## 이번 파일에서 할 일

- [ ] 숫자 입력마다 빈 입력, 글자, 범위 밖 숫자를 다시 입력받게 확인한다.
- [ ] `state.json` 읽기·쓰기 부분을 `try` / `except`로 감싼다.
- [ ] 손상된 JSON 파일이 있을 때 안내하고 기본 퀴즈로 시작하게 한다.
- [ ] Ctrl+C와 입력 종료(`EOFError`) 때 안내 후 가능한 범위에서 저장하고 끝나게 한다.
- [ ] 완료 후 커밋한다.

## 완료 기준

잘못된 입력이나 파일 오류가 있어도 traceback만 출력하며 비정상 종료하지 않는다.
