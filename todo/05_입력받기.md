# 05. 사용자 입력받기

## 이번 파일에서 할 일

- [x] `main.py`를 아래처럼 바꾼다.

```python
name = input("이름을 입력하세요: ")
print(name + "님, 퀴즈 게임에 오신 것을 환영합니다!")
```

- [x] `python3 main.py`를 실행한다.
- [x] 이름을 입력하고 Enter를 눌러 출력 결과를 확인한다.

## 배운 것

`input()`은 사용자가 입력한 글자를 `str` 형태로 돌려준다.

## 완료 기준

입력한 이름이 환영 문구에 표시된다.
