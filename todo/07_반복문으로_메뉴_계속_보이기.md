# 07. 반복문으로 메뉴 계속 보이기

## 이번 파일에서 할 일

- [x] 메뉴를 `while True:` 안에 넣는다.
- [x] 사용자가 5를 선택했을 때 `break`로 반복문을 끝낸다.
- [x] 1을 입력한 뒤 메뉴가 다시 출력되는지 확인한다.
- [x] 5를 입력하면 프로그램이 끝나는지 확인한다.

## 배운 것

`while`은 반복하고, `break`는 반복문을 즉시 끝낸다.

## 완료 기준

5를 선택하기 전까지 메뉴가 계속 표시된다.
