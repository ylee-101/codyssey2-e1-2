# 19. clone과 pull 실습

## 이번 파일에서 할 일

- [ ] 현재 프로젝트 폴더 밖의 안전한 위치에서 `git clone 저장소주소 복제폴더이름`을 실행한다.
- [ ] 복제한 폴더의 `README.md`에 짧은 한 줄을 추가한다.
- [ ] 복제한 폴더에서 변경을 커밋하고 `push`한다.
- [ ] 원래 프로젝트 폴더로 돌아와 `git pull`을 실행한다.
- [ ] README의 한 줄이 원래 폴더에도 들어왔는지 확인한다.

## 완료 기준

`clone`과 `pull`을 모두 한 번 이상 사용했고, 변경이 원래 폴더에 반영되었다.
