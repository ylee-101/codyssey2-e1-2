# 03. 첫 Python 프로그램 만들기

## 이번 파일에서 할 일

- [x] 프로젝트 루트에 `main.py` 파일을 만든다.
- [x] 아래 코드를 입력한다.

```python
print("나만의 퀴즈 게임을 시작합니다!")
```

- [x] 터미널에서 `python3 main.py`를 실행한다.
- [x] 메시지가 출력되면 아래 명령으로 첫 기록을 남긴다.

```bash
git add README.md main.py todo
git commit -m "Feat: 퀴즈 게임 시작 화면 추가"
git push -u origin main
```

## 배운 것

`print()`는 화면에 글자를 출력하는 함수다.

## 완료 기준

명령 실행 후 문장이 화면에 보이고, GitHub에도 첫 커밋이 올라갔다.
