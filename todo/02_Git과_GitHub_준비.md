# 02. Git과 GitHub 준비

## 이번 파일에서 할 일

- [x] 터미널에서 `git --version`을 실행해 Git 설치를 확인한다.
- [x] GitHub에서 빈 저장소를 하나 만든다. 저장소 이름은 원하는 이름으로 정한다.
- [x] 이 폴더에서 `git init`을 실행한다.
- [x] GitHub 저장소의 HTTPS 주소를 복사해 `git remote add origin 저장소주소`를 실행한다.

## 알아둘 말

- Git: 내 컴퓨터에서 변경 이력을 기록하는 도구
- GitHub: Git 기록을 인터넷에 올려 두는 서비스

## 완료 기준

`git remote -v`를 실행했을 때 GitHub 주소가 보인다.
