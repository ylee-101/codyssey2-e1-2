# 06. 조건문으로 메뉴 선택하기

## 이번 파일에서 할 일

- [x] `main.py`에 1. 퀴즈 풀기 / 5. 종료 메뉴를 출력한다.
- [x] `input()`으로 메뉴 번호를 받는다.
- [x] `if`, `elif`, `else`를 사용해 1이면 준비 문구, 5이면 종료 문구, 그 외에는 오류 문구를 출력한다.
- [x] 1, 5, 다른 값을 각각 입력해 확인한다.
- [ ] 완료 후 커밋한다: `git add main.py && git commit -m "Feat: 조건문 기반 메뉴 선택 추가" && git push`

## 배운 것

조건문은 입력값에 따라 다른 코드를 실행한다.

## 완료 기준

1, 5, 다른 값 모두 서로 다른 문구를 출력한다.
