# 18. 전체 테스트와 스크린샷

## 이번 파일에서 할 일

- [ ] 메뉴 1~5를 모두 한 번씩 실행한다.
- [ ] 퀴즈 추가 → 목록 확인 → 재실행 후 유지 → 퀴즈 풀기 → 점수 확인 순서로 테스트한다.
- [ ] 잘못된 입력(`abc`, 빈 Enter, `9`)도 테스트한다.
- [ ] `docs/screenshots` 폴더를 만들고 메뉴, 추가, 목록, 플레이, 점수 화면을 캡처한다.
- [ ] `git log --oneline --graph`를 실행하고 결과를 캡처한다.

## 완료 기준

필수 기능 화면과 Git 로그 화면의 캡처가 준비되었다.
