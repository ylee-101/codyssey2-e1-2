# 14. 최고 점수 기능

## 이번 파일에서 할 일

- [ ] 게임 전체에 `best_score` 값을 만든다. 처음 값은 0이다.
- [ ] 퀴즈를 모두 푼 뒤 현재 정답 수가 최고 점수보다 큰지 비교한다.
- [ ] 더 크면 최고 점수를 갱신하고 안내 문구를 출력한다.
- [ ] 메뉴에 `4. 점수 확인`을 넣고 최고 점수를 출력한다.
- [ ] 아직 게임을 풀지 않은 경우의 안내도 넣는다.
- [ ] 완료 후 커밋한다.

## 완료 기준

퀴즈를 푼 뒤 메뉴 4번에서 최고 점수를 확인할 수 있다.
